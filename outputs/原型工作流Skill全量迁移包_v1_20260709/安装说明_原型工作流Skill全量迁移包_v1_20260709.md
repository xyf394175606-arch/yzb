# 原型工作流 Skill 全量迁移包安装说明

## 包含内容

- `skills/requirement-analysis/`：需求分析 skill。
- `skills/axure-prototype-design/`：Axure 风格原型结构设计 skill。
- `skills/requirements-to-axure-html-prototype/`：需求到可点击 HTML 原型、原型反馈闭环 skill。
- `project-rules/高保真原型_新任务原型工作流SOP_v1_20260708.md`：本项目沉淀的新任务原型工作流 SOP。
- `install.sh`：安装 3 个 skill 的脚本。

## 安装方式

在目标电脑解压压缩包后，进入解压目录执行：

```bash
bash install.sh
```

安装目标目录：

- 如果设置了 `CODEX_HOME`，安装到 `$CODEX_HOME/skills`。
- 如果没有设置 `CODEX_HOME`，安装到 `$HOME/.codex/skills`。

如果目标目录已存在同名 skill，脚本会先备份到：

```text
$HOME/.codex/skills_backup_YYYYMMDD_HHMMSS/
```

## 安装后验证

确认下面 3 个文件存在：

```bash
ls ~/.codex/skills/requirement-analysis/SKILL.md
ls ~/.codex/skills/axure-prototype-design/SKILL.md
ls ~/.codex/skills/requirements-to-axure-html-prototype/SKILL.md
```

如果目标电脑使用了自定义 `CODEX_HOME`，请把 `~/.codex` 替换为对应目录。

## SOP 复制方式

项目 SOP 不会由安装脚本自动写入项目，避免误改其他项目结构。

需要在新项目中使用时，手动复制：

```bash
cp project-rules/高保真原型_新任务原型工作流SOP_v1_20260708.md /path/to/project/00_项目规则/
```

## 推荐使用流程

- 新任务：`requirement-analysis` -> `axure-prototype-design` -> `requirements-to-axure-html-prototype`
- 原型反馈：优先使用 `requirements-to-axure-html-prototype`
- 页面规则倒推：优先使用 `requirement-analysis`
- 原型结构、导航、弹窗归属调整：使用 `axure-prototype-design`
- 版本发布前：检查页面可访问、左侧导航层级、弹窗归属、黄色说明区、旧口径残留、静态校验结果。

## 注意事项

- 本迁移包只安装 skill，不安装项目代码、不修改目标项目文件。
- 迁移包内的 `骨干教员 / 专业教员` 等内容只是原型任务样例，不代表所有新项目都必须沿用。
- 如果目标电脑已有同名 skill，安装后发现不符合预期，可从备份目录恢复。
