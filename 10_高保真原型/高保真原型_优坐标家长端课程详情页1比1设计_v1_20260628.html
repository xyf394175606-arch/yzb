右侧黄色说明区
字段规则、按钮结果、页面定位、平台默认能力和状态说明统一放这里，不放进手机页面线框。
页面定位

本页固定为体验课详情成交页，用于介绍课程价值、建立信任和承接购买，不承担已购后服务流程展示。

字段口径
  • 当前售价、底部价格：当前原型按后台课程规格中的单价字段展示。
  • 划线原价：当前原型按后台原价字段展示。
  • 销量：当前原型按后台虚拟销量字段展示。
  • 收藏标签：由系统后台配置获取，用于前台摘要标签展示。
  • 摘要标签：好课热销、收藏标签、学科、学段等标签统一使用同一颜色。
  • 最新下单滚动带：不再由编辑课程页维护；原型按前端展示数据表达，时间为纯前端展示，按当前时间前15-20分钟随机生成。
  • 评价摘要与评价总数：通过后台课程管理列表页操作列的“评论管理”弹窗维护，当前按后台自定义评论假数据展示。
  • 价格区右侧第一行文案：按适用年级首选项 + 所选科目组合生成。
  • 课程封面图：同时作为前台详情首屏主视觉和推荐课程卡片封面来源。
  • 精选好课：通过后台课程管理列表页操作列的“关联课程”弹窗维护关联课程列表、顺序、销量和跳转目标；前台默认最多展示4个，无关联课程时不展示，加载更多可查看全部关联课程。
首屏滚动成交带

红框区域为循环滚动的最新下单提示，目的是营造成交氛围并刺激用户尽快下单。前台展示脱敏手机号与下单时间，其中时间为纯前端展示，按当前时间前15-20分钟随机生成。

导航锚点
  • 课程内容：点击后回到当前课程详情页顶部。
  • 课程评价：点击后跳转到课程评价模块。
  • 课程详情：课程图文内容锚点。
  • 课程推荐：精选好课区域锚点。
按钮结果
  • 立即购买：统一进入确认订单页，不在详情页直接完成 SKU 选择。
  • 收藏 / 分享 / 客服：登录后可用，未登录先进入登录页承接。
  • 精选好课卡片 / 立即抢购：都进入对应课程详情页，不直接下单。
  • 加载更多关联课程：查看当前课程已关联的全部精选好课。
  • 查看更多评价：进入课程评价列表页占位。
平台默认能力

右上角更多采用小程序标准更多能力，不承载自定义业务动作。原型说明文案明确备注：回首页、转发。

本期范围

AI 导购不属于本期功能，因此即使设计图中存在相关元素，本次原型不展示该入口。

页面职责

确认订单页承接课程详情页的立即购买动作，按照商品详情下单页形态展示课程商品、购买数量、课时信息、家长信息、学员选择、推荐人电话、订单备注和立即支付入口。

字段规则
  • 顶部商品图：展示当前课程封面或下单页商品宣传图。
  • 实付价：展示当前订单应付金额，随购买数量和课程价格联动。
  • 购买数量：默认 1，支持减号/加号调整；最小值为 1。
  • 课程（课时）：展示购买课程课时数和价格。
  • 交付课程（课时）：展示赠送或交付课时数和价格，当前示例为 1 课时、价格 0.0。
  • 家长信息：默认读取当前登录家长手机号并脱敏展示。
  • 选择学员：必填；无学员时展示“暂无学员信息”，后续需补充选择或新增学员承接。
  • 推荐人联系电话：选填，输入手机号。
  • 订单备注：选填，多行文本。
按钮规则
  • 返回：回到课程详情页。
  • 数量减号：数量为 1 时不可继续减少。
  • 数量加号：增加购买数量后同步刷新实付价和底部立即支付金额。
  • 立即支付：校验必填项，当前至少需选择学员；通过后进入支付流程，本原型不展开真实支付页。
范围说明

本轮按截图补齐确认订单页视觉和字段规则；支付结果、优惠券、开票、库存轮询、学员新增弹窗和支付失败状态后续在订单专项中继续细化。

页面职责

该页承接详情页“查看更多评价”跳转，用于后续扩展完整评价列表能力。

当前实现

详情页展示评价摘要，本页仅做跳转关系占位，后续可继续补充筛选、排序、分页和评价标签。

登录拦截规则

收藏、分享、客服均需要登录后使用。登录成功后回到课程详情页继续当前动作。

当前实现

原型中用独立登录页表达承接链路，不展开真实登录方式和账号体系规则。

页面职责

该页用于承接已登录用户的课程咨询动作，真实接入时可替换为客服会话页或咨询工作台。

边界说明

本页不展示营销成交信息，也不承接购买后的待约课状态。

跳转规则

推荐课程点击课程卡片后进入该课程详情页，再由该课程详情页继续承接购买。

当前实现

本原型用占位详情页说明跳转关系，不在当前课程详情页直接打开推荐课程的 SKU 面板。

页面职责

后台课程管理列表页用于维护课程清单、筛选课程范围，并通过“编辑”进入课程编辑页，通过“评论管理”进入当前课程评论管理弹窗，通过“关联课程”进入当前课程关联课程弹窗。它是后台课程、评论和关联课程运营入口页。

列表操作

列表对齐真实后台管理页结构，需展示课程信息、分类/学科、适用年级、单价、价格、课时时长、评分、关联老师、状态，并通过“详情 / 评论管理 / 关联课程 / 编辑”完成查看、评论维护、关联课程维护和课程编辑。

筛选规则
  • 课程名称：文本输入，支持按课程名称关键词模糊搜索。
  • 课程类别：下拉单选，来源于数字字典；默认“所有类别”。
  • 科目：下拉单选，来源于数字字典；默认“所有科目”。
  • 年级：下拉单选或多选，来源于适用年级字典；默认“所有年级”。
  • 课程状态：下拉单选，包含启用、停用等状态；默认“所有状态”。
  • 课程类型：下拉单选，包含试听课、正课；默认“所有类型”。
  • 搜索：按当前筛选条件刷新课程列表。
  • 重置：清空筛选条件并恢复默认列表。
  • 收起：折叠筛选区，仅保留列表主体。
列表字段规则
  • 勾选框：用于批量选择课程，本轮仅展示入口，不展开批量操作。
  • 课程信息：展示课程封面缩略图、课程名称、课程ID。
  • 分类/学科：展示课程类别与所属学科。
  • 适用年级：展示已配置年级，超出展示数量时使用“+N”折叠。
  • 单价：展示原价、会员价、平台服务费等价格字段。
  • 价格：展示对外售卖价格组合，用于后台快速核对。
  • 课时时长：展示课程类型、单节时长和总课时数。
  • 评分：展示后台配置或统计评分。
  • 关联老师：展示当前关联老师数量。
  • 状态：展示课程启用/停用状态。
按钮规则
  • 查看家长端详情页：跳转当前家长端课程详情页，用于核对前台展示效果。
  • 新增课程：进入编辑课程页，用于创建新课程，本轮复用编辑页表达。
  • 详情：查看当前行课程详情，本轮仅作为列表操作入口展示。
  • 评论管理：打开当前行课程的评论管理弹窗，用于新增、编辑、启用、停用或删除评论假数据。
  • 关联课程：打开当前行课程的关联课程弹窗，用于选择关联课程并维护前台精选好课展示。
  • 编辑：进入当前行对应的编辑课程页，编辑后驱动前台课程详情展示。
  • 刷新图标：按当前筛选条件重新加载列表。
  • 密度/全屏/列设置类图标：按后台标准列表工具处理，本轮不展开独立业务规则。
  • 分页：切换页码或每页条数后刷新课程列表。
与前台关系

该页提供课程编辑、评论管理和关联课程入口。家长端课程详情页的标题、标签、价格和详情图由编辑课程页维护；评价摘要与评价总数由课程列表页的评论管理弹窗维护；精选好课由课程列表页的关联课程弹窗维护；滚动成交带按前端展示规则处理。

页面职责

后台编辑课程页用于维护课程基础字段、价格字段、课程介绍图片、课程标签和封面图。课程评价 / 评论和关联课程相关功能不在本页维护，统一从课程管理列表页对应操作入口进入。

字段逐项说明
课程名称

字段定义：前台课程标题主来源。规则：单行文本，最多100字，必填。交互方式：文本输入。影响：未填写时不能完整承接前台标题展示。

课程类别 / 所属学科

字段定义：前台类目与学科展示来源。规则：均为下拉单选，来源于数字字典。交互方式：下拉选择。影响：同时用于后台筛选与前台摘要标签展示。

适用年级

字段定义：前台学段展示来源。规则：多选勾选，来源于数字字典。交互方式：复选项多选。影响：同步影响后台列表适用年级列与前台课程学段展示。

课程介绍（最多10张图片）

字段定义：前台课程详情长图内容来源。规则：最多10张，支持拖拽排序，建议800×600px，支持JPG/PNG。交互方式：图片上传、排序、删除。影响：前台详情图文顺序按后台配置顺序展示。

课程标签

字段定义：前台标签来源。规则：最多5个，单标签最多10字；优先从数字字典选择，也允许手动补充少量自定义标签。交互方式：字典选择 + 手工输入。影响：前台摘要区按已配置标签展示。

课程封面图

字段定义：前台详情主视觉与推荐课程卡片封面来源。规则：单图上传，建议1:1比例、800×800px，支持JPG/PNG，单图不超过10MB。交互方式：上传、替换。影响：同时驱动详情页和推荐卡片封面。

课程配置 / 价格字段

字段定义：试听课/正课类型与价格展示来源。规则：课程配置为单选；单价、会员单价、平台服务费、总课时数、原价、会员价、单节课时长为数值输入；虚拟销量、虚拟评分为前台信任增强字段。交互方式：单选切换 + 数值输入。影响：同步影响前台价格区、后台列表与推荐展示。

弹窗职责

该弹窗由课程管理列表页操作列“评论管理”打开，用于维护当前课程的评论假数据，包括新增、编辑、启用、停用和删除。

字段规则
  • 课程绑定：弹窗按当前课程行打开，标题展示当前课程名称。
  • 筛选区：支持按用户昵称、展示状态、评分筛选评论列表。
  • 用户昵称：文本输入，必填。
  • 评分：星级选择，用于前台评价摘要展示。
  • 评论内容：多行文本输入，必填，用于前台评价摘要展示。
  • 评价时间：日期时间选择，用于后台记录和前台展示候选。
  • 排序值：数值越小越靠前。
  • 状态：启用后进入前台摘要候选，停用后不展示。
按钮结果
  • 新增评论：在评论表格末尾新增一条评论行。
  • 启用 / 停用：切换当前评论是否进入前台评价摘要候选。
  • 删除：移除当前评论假数据。
  • 取消：关闭弹窗并返回课程管理列表页。
  • 保存评论：保存当前表单内容，回显到评论列表，并按启用状态和排序影响前台评价摘要。
弹窗职责

该弹窗由课程管理列表页操作列“关联课程”打开，用于给当前课程选择精选好课。运营在弹窗中搜索、筛选并多选课程，确认后建立推荐关联。

交互规则
  • 支持按课程名称、课程类别、所属学科、课程状态筛选候选课程。
  • 支持多选关联，确认后返回课程管理列表页，关联结果用于当前课程前台精选好课展示。
  • 已关联结果展示课程名称、封面、分类/学科、价格、排序值和移除操作。
  • 推荐顺序由关联课程弹窗中的排序值控制，前台按该顺序展示精选好课。
  • 前台默认最多展示4个关联课程；超过4个时通过“加载更多”查看全部关联课程。
  • 当前课程没有关联课程时，前台不展示精选好课模块。
