# 优坐标首页改版与后台配置原型说明

## 1. 背景

本原型基于用户提供的优坐标家长端新版首页截图，补充后台首页装修工作台，验证首页运营内容的编辑、草稿、预览、发布和前台读取链路。

## 2. 目标

- 还原移动端首页的主要视觉层级和模块结构。
- 让管理员可以在 PC 后台集中维护首页模块。
- 让草稿预览和已发布首页产生可见差异。
- 覆盖项目规则要求的异常、空状态、发布失败和配置不完整表达。

## 3. 输入来源

- 用户提供的首页改版截图 `mac_1784104486734.png`。
- `10_高保真原型/高保真原型_优坐标家长端首页复刻_v32_20260615.html`。
- `10_高保真原型/高保真原型_教师类型首页入口配置补强说明_v1_20260713.md`。
- `10_高保真原型/高保真原型_配置弹窗底部操作规范调整说明_v1_20260714.md`。
- 项目 `AGENTS.md` 与首页原型技能规范。

## 4. 页面目标

### 4.1 首页装修工作台（PC）

用于维护 Banner、快捷入口、试听课、教师类型与教师推荐、精品课程、公众号关注和底部导航。默认展示模块列表、草稿状态和手机预览。

### 4.2 家长端首页（移动端）

展示已发布首页，包括定位、Banner、快捷入口、试听课、教师推荐、精品课程、公众号关注和底部导航。首页只读取已发布版本。

## 5. 交互规则

| 操作 | 原型结果 |
| --- | --- |
| 切换首页装修/家长端首页 | 切换 PC 工作台和移动首页 |
| 选择模块 | 打开对应模块配置弹窗，并更新右侧黄色说明 |
| 编辑 | 打开对应配置弹窗 |
| 保存 | 更新草稿并关闭弹窗，普通弹窗底部仅“取消/保存” |
| Banner 保存，发布 | 更新 Banner 草稿并关闭弹窗；正式发布仍通过工作台“发布首页”完成 |
| Banner 图片上传 | 点击“点击上传图片”，选择 jpg/png；超过 2MB 或类型不符时提示错误，合法文件显示文件名 |
| Banner 新增轮播 | 点击“新增轮播”添加一条配置草稿 |
| Banner 删除轮播 | 点击行内“删除”移除当前轮播；至少保留一条 |
| 快捷入口新增 | 点击“新增入口”增加一条入口草稿；最多 10 条 |
| 快捷入口编辑 | 编辑入口名称、跳转目标和地址，保存后进入草稿 |
| 快捷入口删除 | 点击行内“删除”移除入口；至少保留 4 条 |
| 取消/关闭 | 不保存，关闭弹窗 |
| 启用/停用 | 更新草稿展示状态并刷新预览 |
| 删除 | 列表行内二次确认后从当前草稿移除 |
| 预览草稿 | 手机预览读取草稿 |
| 已发布预览 | 手机预览读取已发布版本 |
| 发布首页 | 将草稿复制为已发布版本并刷新家长端 |
| 发布失败 | 显示错误提示，保留草稿，不修改已发布版本 |
| 刷新首页 | 重新读取已发布配置 |
| 首页入口点击 | 显示操作反馈，作为目标页占位结果 |

## 6. 字段和来源

- Banner：按参考截图采用“首页轮播广告 banner”配置页。Banner 是多条轮播广告列表，每条包含图片、跳转目标、跳转地址和轮播时长，列表顺序即轮播顺序；支持新增与行内删除，至少保留一条。
- 快捷入口：采用与 Banner 一致的列表配置弹窗；每条包含 Icon 占位、入口名称、跳转目标和地址，支持新增、编辑和行内删除，数量限制为 4 至 10 条。
- 试听课/精品课程：使用已有优坐标课程命名和价格样例。
- 教师推荐：复用仓库中的教师头像资产，读取样例教师姓名和教学经验。
- 教师类型：默认展示骨干教员、专业教员、英语伴读，一级类型配置规则沿用现有说明。
- 公众号关注：使用示例卡片，不接真实二维码上传。
- 底部导航：首页、全部老师、成为会员、消息、我的。

## 7. 状态说明

- 草稿：后台保存后的编辑版本，只影响草稿预览。
- 已发布：家长端当前读取版本。
- 已启用/已停用：模块是否参与对应版本展示。
- 空状态：模块被删除或停用后，预览区域显示“暂无可展示内容”。
- 发布失败：真实发布请求失败时显示错误提示并保留草稿，当前离线原型不提供演示用的失败按钮。
- 配置不完整：启用模块发布前需要通过字段校验；Banner 需至少保留一条完整轮播；快捷入口需保留 4 至 10 条且每条填写名称、跳转目标和地址。
- 无权限：右侧需求说明记录管理员全量演示，真实无权限态待接入权限中心。
- 读取失败：以说明区和发布错误提示表达，真实接口错误码待数据交互阶段确认。

## 8. 权限差异

本轮按管理员全量权限演示。运营编辑、管理员发布、只读角色和无权限角色的真实权限矩阵未接入，但在右侧黄色说明区中明确标记为后续确认项。

## 9. 数据刷新逻辑

原型使用页面内 mock 配置：`draft` 保存工作台草稿，`published` 保存家长端版本。发布时复制草稿为已发布版本；家长端刷新时重新渲染已发布版本。没有真实接口调用或持久化。

## 10. 暂不覆盖

- 真实上传、裁切、尺寸校验、CDN 和二维码存储。
- 发布审核、历史版本、回滚、预览链接。
- 城市/用户分群首页。
- 教师和课程自动推荐算法。

## 11. 原型自检记录

- 文件采用单文件 HTML，可通过本地 HTTP 服务打开。
- 后台和家长端入口均可切换。
- 普通配置弹窗使用取消/保存双按钮；Banner 弹窗按新版字段使用取消/保存，发布，删除位于轮播项行内。
- 工作台已移除“＋新增模块”、状态条重复“预览草稿”和“模拟发布失败”演示入口；正式预览入口保留在页面顶部，Banner 新增轮播直接在 Banner 配置弹窗内完成。
- 本轮反馈处理：将所有首页模块的侧栏入口和模块行点击统一改为打开所属配置弹窗；弹窗打开时右侧黄色区切换为对应模块需求说明，编辑图标保持同一结果。
- 本轮视觉反馈处理：调整弹窗蒙版与左右侧栏的层级，Banner 配置弹窗打开时左侧模块列表和右侧黄色说明保持清晰可读，弹窗和工作台主体仍保留蒙版效果。
- 本轮反馈处理：Banner 弹窗参考用户截图改为“首页轮播广告 banner”页面；移除设置区、指示点样式和旧缩略图列表，改为每条轮播独立展示图片上传区域、跳转目标、跳转地址、轮播时长、400*300 尺寸说明和行内删除，并增加“新增轮播”。
- 本轮字段调整：移除标题、副标题、落播时间、圆角图片、知识点颜色、按钮文案和展示时间字段；底部按钮调整为“取消/保存，发布”，其中“保存，发布”在原型中保存为草稿，正式发布仍由工作台发布首页完成。
- 前台和后台使用同一份页面内 mock 配置，并区分草稿和已发布版本。
- 浏览器验证：后台默认渲染 7 个首页模块；Banner 编辑弹窗可打开，展示图片、跳转目标、跳转地址、轮播时长和新增轮播；底部显示“取消/保存，发布”，删除位于行内。
- 发布链路验证：发布成功提示“首页已发布，家长端读取新版本”，切换家长端后显示已发布版本；失败处理保留为真实发布请求失败后的异常态。
- 草稿隔离验证：停用快捷入口后，草稿预览显示“快捷入口暂无可展示内容”；已发布预览仍保留已发布配置。
- 响应式验证：移动断点样式已生效，390px 测试视图中手机首页、课程、教师推荐和底部导航可见；桌面视图中工作台、手机预览和黄色需求说明区均可见。
- 资源与脚本检查：桌面测试视图图片失败数为 0，浏览器控制台 error/warning 为 0。
- 代码校验：`saveForm` 对启用模块的主标题空值进行拦截，`publish` 对不完整启用模块阻止发布；当前浏览器驱动对清空输入框的自动化操作不稳定，该异常态未作为交互实测通过项记录。
- Banner 交互校验：图片区域可选择 jpg/png，类型错误或超过 2MB 时提示；轮播地址和时长可编辑；新增、删除和保存后草稿列表同步更新。
- 快捷入口交互校验：配置弹窗采用列表形式；新增上限 10 条、删除下限 4 条；名称、跳转目标或地址为空时提示配置不完整。

## 12. 待确认问题

- Banner 图片实际规格、裁切和存储规则。
- Banner 跳转目标枚举、地址格式及站外链接限制。
- Banner 轮播时长范围、默认值、排序和发布前真实轮播预览规则。
- 快捷入口 Icon 上传规格、跳转目标枚举、地址格式、排序和用户群差异化规则。
- 首页分城市/角色/用户群配置。
- 课程和教师的真实排序口径。
- 发布是否需要审核、回滚和版本对比。
- 图片规格、裁切、存储和兜底图；标题、副标题、落播时间、圆角图片、知识点颜色、按钮文案、展示时间和指示点样式均不在本轮范围。
