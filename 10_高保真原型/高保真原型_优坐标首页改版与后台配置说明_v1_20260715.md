# 优坐标首页改版与后台配置原型说明

## 1. 背景

本原型基于用户提供的优坐标家长端新版首页截图，补充后台首页装修工作台，验证首页运营内容的编辑、草稿、预览、发布和前台读取链路。

## 2. 目标

- 还原移动端首页的主要视觉层级和模块结构。
- 让管理员可以在 PC 后台集中维护首页模块。
- 让草稿预览和已发布首页产生可见差异。
- 覆盖项目规则要求的异常、空状态、发布失败和配置不完整表达。

## 4. 页面目标

### 4.1 首页装修工作台（PC）

用于维护 Banner、快捷入口、试听课、平台服务保障、教师类型与教师推荐、精品课程、公众号关注和底部导航。默认展示模块列表、草稿状态和手机预览。

### 4.2 家长端首页（移动端）

展示已发布首页，包括定位、Banner、快捷入口、试听课、平台服务保障、教师推荐、精品课程、公众号关注和底部导航。首页只读取已发布版本。

### 4.3 空白页样式（PC）

作为首页装修工作台的左侧子入口，仅保留左侧导航、空白中间工作区和右侧黄色需求说明，用于后续页面布局起稿或评审对照；不承载任何首页配置业务数据。

| 编辑 | 打开对应配置弹窗 |

| 快捷入口新增 | 点击“新增入口”增加一条入口草稿；最多 10 条 |
| 快捷入口编辑 | 编辑入口名称、跳转目标和地址，保存后进入草稿 |
| 快捷入口删除 | 点击行内“删除”移除入口；至少保留 4 条 |
| 快捷入口 Icon 上传 | 点击 Icon 占位选择 jpg/png；合法文件更新草稿 Icon，错误文件提示失败 |
| 试听课图片上传 | 点击固定广告位图片区域选择 jpg/png；合法文件显示文件名，错误文件提示失败 |
| 试听课保存 | 校验主标题和三个广告位必填字段，成功后保存草稿并关闭弹窗 |
| 教师/课程图片上传 | 点击固定广告位图片区域选择 jpg/png；合法文件显示文件名，错误文件提示失败 |
| 教师/课程保存 | 校验主标题和三个广告位必填字段，成功后保存草稿并关闭弹窗 |
| 取消/关闭 | 不保存，关闭弹窗 |
| 启用/停用 | 更新草稿展示状态并刷新预览 |
| 删除 | 列表行内二次确认后从当前草稿移除 |
| 预览草稿 | 手机预览读取草稿 |
| 已发布预览 | 手机预览读取已发布版本 |
| 发布首页 | 将草稿复制为已发布版本并刷新家长端 |
| 发布失败 | 显示错误提示，保留草稿，不修改已发布版本 |
| 刷新首页 | 重新读取已发布配置 |
| 首页入口点击 | 显示操作反馈，作为目标页占位结果 |

## 6. 字段和来源

- Banner：按参考截图采用“首页轮播广告 banner”配置页。Banner 是多条轮播广告列表，每条包含图片、跳转目标、跳转地址和轮播时长，列表顺序即轮播顺序；支持新增与行内删除，至少保留一条。
- 快捷入口：采用与 Banner 一致的列表配置弹窗；每条包含可更换 Icon、入口名称、跳转目标和地址，支持新增、编辑和行内删除，数量限制为 4 至 10 条。
- 试听课：改为固定三位广告位；配置主标题、每个位的图片、跳转目标和跳转地址，前台按固定位置展示；后台模块名称和前台区块名称统一为“试听课”。
- 平台服务保障：后台维护模块主标题（20 字以内）、1 张图片和 1 个跳转链接，不支持新增、删除或排序；前台按已发布版本展示一张完整保障图片。
- 教师类型与推荐：配置主标题（最多 10 字）、每类默认展示老师数（1 到 20）和全部教师类型多选标签；勾选即首页展示，未勾选不展示；支持全选、清空和已选数量反馈，前台按排序展示每类前 N 位老师，标签或老师卡片超出一屏可横滑。
- 精品课程：配置主标题（最多 10 字）、每类默认展示课程数（1 到 20）和课程分类多选标签；前台按排序展示每类前 N 门课程，标签或课程卡片超出一屏可横滑。
- 教师推荐：复用仓库中的教师头像资产，读取样例教师姓名和教学经验。
- 教师类型：默认展示骨干教员、专业教员、英语伴读，一级类型配置规则沿用现有说明。
- 公众号关注：采用快捷入口弹窗的字段化编辑方式，配置主标题、副标题、按钮文案、跳转链接和是否展示；使用示例卡片，不接真实二维码上传。
- 底部导航：固定首页、全部课程、全部老师、会员、消息、我的 6 个入口；后台可编辑展示标题、跳转页面和是否展示，首页必须展示且至少保留一个入口展示。

## 7. 状态说明

- 草稿：后台保存后的编辑版本，只影响草稿预览。
- 已发布：家长端当前读取版本。
- 已启用/已停用：模块是否参与对应版本展示。
- 空状态：模块被删除或停用后，预览区域显示“暂无可展示内容”。
- 发布失败：真实发布请求失败时显示错误提示并保留草稿，当前离线原型不提供演示用的失败按钮。
- 配置不完整：启用模块发布前需要通过字段校验；Banner 需至少保留一条完整轮播；快捷入口需保留 4 至 10 条且每条填写名称、跳转目标和地址。
- 无权限：右侧需求说明记录管理员全量演示，真实无权限态待接入权限中心。
- 读取失败：以说明区和发布错误提示表达，真实接口错误码待数据交互阶段确认。

## 8. 权限差异

本轮按管理员全量权限演示。运营编辑、管理员发布、只读角色和无权限角色的真实权限矩阵未接入，但在右侧黄色说明区中明确标记为后续确认项。

## 9. 数据刷新逻辑

原型使用页面内 mock 配置：`draft` 保存工作台草稿，`published` 保存家长端版本。发布时复制草稿为已发布版本；家长端刷新时重新渲染已发布版本。没有真实接口调用或持久化。

## 10. 暂不覆盖

- 真实上传、裁切、尺寸校验、CDN 和二维码存储。
- 发布审核、历史版本、回滚、预览链接。
- 城市/用户分群首页。
- 教师和课程自动推荐算法。
