## 已确认规则

| 主题 | 已确认规则 | 来源 |
| --- | --- | --- |
| 会话 | 每位家长与每位咨询师一条会话，会话内管理多个服务单 | 用户确认 |
| 服务单 | 六状态；发布推荐前必须绑定学员；关闭需标准原因和补充说明 | 用户确认 |
| 推荐 | 一个首选、最多两个备选；必须写匹配理由；允许跨老师推荐 | 用户确认 |
| 有效转化 | 已支付且未即时取消的购买记为转化，后续履约结果继续回写 | 用户确认 |
| 联系渠道 | 运营按顾问配置平台IM、企业微信和电话入口，可同时展示 | 用户确认 |
| 电话隐私 | 默认双向隐私号；运营可将指定顾问切换为真实电话 | 用户最终调整 |
| 容量 | 统计且可配置，默认无限；只有配置了上限才执行限制 | 用户最终调整 |
| 评价 | 真实评价独立保存后台；前台评分和人数采用运营维护最终值 | 用户最终调整 |
| 信用分 | 家长可见12分制，四档处置，2/4/6/12累计扣分 | 用户确认方向并要求制定版本 |
| 申诉 | 同一事件允许重复申诉 | 用户最终调整 |
| 企微 | 接入企业微信会话存档，关联会话和服务单进入风控 | 用户确认 |
| 电话 | 双向隐私号与真实电话均接入平台呼叫、录音、转写和风控 | 用户最终确认 |
| 服务时段 | 平台提供24小时服务，响应时长连续计算 | 用户最终确认 |
| 近期服务学员 | 首期由运营配置近90天展示值 | 用户最终确认 |
| 交付范围 | 专业展示、销售闭环、企微/电话/音视频和风控全部交付 | 用户最终确认 |

## 建议确认

| 问题 | 建议默认 | 影响范围 |
| --- | --- | --- |
| 重复申诉准入 | 次数不限，但需新增证据或新增说明；不同复核人处理 | 申诉队列、SLA |
| 信用恢复 | 扣2/4/6分分别观察30/60/90天；扣12分需重新认证 | 整改、恢复 |
| 首响计时 | 24小时连续计时，首响分钟阈值由运营配置 | 服务评分、超时 |
| 内容自动分析 | 平台文字、企微存档文字、全部语音转写自动分析；图片文件按风险查看 | 风控成本、覆盖 |
| 老师与课程推荐关系 | 老师主卡展示关联课程，并可追加独立课程 | 推荐方案、购买 |
| 真实电话例外审批 | 运营切换真实电话时必填原因，记录生效时间和操作人 | 联系渠道、审计 |

## 风险与依赖

- 外部联系渠道越多，统一会话、风控和购买归因越依赖第三方接口。
- 重复申诉若无新增证据门槛，可能造成风控队列被重复材料占用。
- 容量默认无限可能造成服务超载，需要用未响应、超时和工作量统计及时暴露风险。
