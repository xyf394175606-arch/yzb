# 需求澄清：优坐标首页改版与后台配置

## 1. 背景

本清单用于确认优坐标首页改版中首页模块的后台配置边界、发布机制、内容来源和异常处理口径。

## 2. 已确认方案

| 事项 | 结论 | 来源 |
| --- | --- | --- |
| 配置范围 | 全首页模块 | 用户选择 |
| 视觉策略 | 家长端高还原截图，后台沿用管理台风格 | 用户选择 |
| 发布机制 | 保存草稿后发布 | 用户选择 |
| 内容编辑 | 可编辑字段与示例素材，不接真实上传 | 用户选择 |
| 权限 | 本轮按管理员全量权限演示 | 用户选择 |
| 后台组织 | 首页装修工作台 | 用户选择 |
| 交付范围 | 默认按家长端首页 + 后台工作台联动实现 | 方案默认值，用户未另行否定 |

## 3. 必须确认问题

| 编号 | 问题 | 影响 | 原型处理 |
| --- | --- | --- | --- |
| Q1 | Banner 是否需要多张轮播及轮播间隔配置 | Banner 编辑字段和前台交互 | 原型支持多 Banner 列表，轮播间隔标为示例配置 |
| Q2 | 首页模块是否允许按角色/城市差异化展示 | 权限、地域和版本模型 | 原型只演示全局首页，保留待确认说明 |
| Q3 | 课程与教师数据的真实排序来源 | 推荐模块的自动/手动规则 | 原型使用手动选择样例数据 |
| Q4 | 发布是否需要审核、预览链接或回滚 | 发布流程和操作权限 | 原型按管理员直接发布，审核/回滚列为后续依赖 |
| Q5 | 公众号二维码、Banner 和 Icon 的尺寸及存储规则 | 素材校验与上传能力 | 原型只展示预览，不实现真实上传 |

## 4. 暂不纳入范围

- 真实接口、数据库、素材上传、裁切和 CDN。
- 多租户、城市/用户分群首页。
- 审核流、发布回滚、历史版本对比。
- 课程和教师推荐的自动算法。

## 5. 风险与依赖

- 若后续确认需要审核或分群发布，当前“管理员直接发布”的流程需要扩展。
- 若真实数据无法提供首页需要的封面、头像和状态字段，前台展示口径需回流数据交互阶段。

## 6. 下一步动作

- 将未决项转入需求分析中的待确认问题。
- 使用已确认方案实现可点击 HTML 原型。
