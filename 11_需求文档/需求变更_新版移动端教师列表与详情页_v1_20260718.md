# 需求变更：新版移动端教师列表与详情页

## 背景

教师列表与教师详情页需按新版视觉参考重构，以更清晰展示教师能力、适配学生、教学成果、家长评价、课程和顾问咨询入口。改版前版本已在 `10_高保真原型/历史备份/20260718_新版移动端改版前/` 封存。

## 目标

- 以新版移动端教师列表和教师详情页替换旧版页面信息结构。
- 保留已确认的课程下单、区域展示、评价、教师类型、教师标签和关联课程规则。
- 让教师页面展示资料可以维护新版前台新增内容。

## 输入来源

- 新版教师详情页与全部老师列表页视觉参考图。
- 已封存的老师列表 V1 原型及已确认需求变更说明。
- 教师详情页使用原始 440 x 2198 参考图作为 V2 的视觉对照基准，最终页面由真实 HTML/CSS 组件渲染。

## 本次变更

### 全部老师列表页

- 顶部筛选调整为：年级、学科、教员类型、综合排序。
- 综合排序支持综合、评分、已授课时长、收藏数；移除“收藏”独立筛选入口。
- 教师卡展示：头像、教员类型、主讲学段/科目、学历与教学经验、标签、简介、评分、已授课时长、收藏数。
- 点击教师卡进入教师详情页；任一筛选条件变化后立即刷新老师卡，筛选无结果时展示全部老师。

#### 列表页来源与展示规则

- 年级通过年级数据字典调用，按老师资料中的授课年级筛选；学科通过学科数据字典调用，按老师资料中的授课学科筛选；教员类型通过教师类型维护调用，支持一级类型及其二级类型。
- 每次变更年级、学科、教员类型或综合排序后，立即按当前条件刷新老师卡；若无老师符合筛选条件，自动回退展示全部老师，并继续执行当前综合排序规则。
- 综合排序按运营维护的前端展示顺序从大到小展示；评分按家长评分从高到低展示，相同评分再按前端展示顺序从大到小展示；授课时长按已完成授课时长从高到低展示，相同时长再按前端展示顺序从大到小展示；收藏按收藏人数从高到低展示，相同收藏人数再按前端展示顺序从大到小展示。
- 教师卡头像读取认证图片资料；名称、主讲范围、教学经验和简介读取教师基本资料及页面展示资料；标签读取教师标签维护。
- 毕业院校、最高学历均来自基本认证资料，并由各自的列表展示开关控制。两项均开启时组合展示，仅开启一项时只展示该项，均关闭时隐藏学历信息。
- 评分、授课时长、基础收藏人数来自业务统计；虚拟收藏人数来自页面展示资料，前台展示两者合计。
- 仅已上架、未作废且允许前台展示的老师进入列表；教师资料、展示配置或统计保存后立即刷新对应老师卡。

### 教师详情页

- 页签收敛为老师介绍、家长评价、购买课程三个锚点。
- 老师介绍包含教师头部、适合这样的孩子、个人简介、主讲科目、教学成果、提分案例。
- 教师所在区域保留在姓名下方、指标上方，仅展示省、市、区县；不展示详细地址。
- 家长评价展示总评分、星级分布和节选评价，读取现有全部评价数据。
- 购买课程仍只展示已关联且可售课程；课程卡点击后直接带入当前课程进入确认订单页。
- 底部固定区调整为顾问名片、打电话、在线询；不再提供底部立即购买和课程选择入口。

### 顾问入口

- 打电话：打开拨打顾问确认弹窗，确认后调用系统电话能力。
- 在线询：打开在线咨询弹窗，作为真实 IM 会话的承接入口；本轮不展开会话页面。

| 前台展示内容 | 字段/数据组 | 后台来源 | 编辑方式 | 展示规则 |

### 本次字段一致性变更

- 详情页不再以整张截图作为可见内容，不保留页面内独立固定的姓名、评价、课程、案例、顾问或统计数据。
- 咨询顾问不在编辑教师资料中配置；顾问资料与教师关联关系由独立顾问维护与关联入口承接。
- 教学经验、提分率为展示配置；授课时长、收藏人数、家长评分为只读统计，禁止在教师资料中手工录入。
- 保存页面展示资料后刷新教师详情页对应模块；课程、评价、统计变化后由各自管理入口刷新详情展示。
- 毕业院校与最高学历分别增加教师列表展示开关，默认均展示；开关不影响认证资料留存、审核或教师详情页。
- 编辑教师认证资料移除微信 OpenID、企业微信 OpenID；身份证号改为非必填；资质证明与教师头像、形象照片统一归入认证图片资料；弹窗内部不再保留左侧锚点导航。
- 页面展示资料按详情页顺序维护：展示基础、展示标签与指标、适合这样的孩子、教师简介、教学成果、提分案例；删除授课特色配置。
- 适合这样的孩子增加总展示开关，默认关闭；教师简介移除展示开关；提分案例调整为主标题、副标题、强化副标题、Icon、是否展示和删除操作。
- 全部评价弹窗的隐藏/展示只控制单条评价内容在教师详情页的可见性，不删除评价记录，也不影响评价总数、评分和星级汇总。
- 页面展示资料收敛为四组：展示基础、广告位、教师简介、教学成果；广告位默认预置 3 条，主讲科目最多选择 5 个。
- 新增/编辑教师的页面展示资料不展示教师审核状态或上下架状态；上述状态仅在后台教师列表中查看和处理。
- 基本认证资料新增年级、学科两个多选字段，分别调用年级、学科数据字典；保存后同步后台教师列表对应列，并作为前台全部老师列表的筛选来源。前台展示多个年级时按高中、初中、小学优先级归并展示，多个学科时展示第一个已选学科。

### 后台教师列表字段

后台“教师列表”用于运营核对教师资料、统计与状态，列表字段与新增/编辑教师弹窗保持一致，不另行维护重复资料。

| 列表字段 | 调用来源 | 展示规则 |
| --- | --- | --- |
| 教师姓名 | 基本认证资料中的教师真实姓名、登录手机号 | 同一单元格展示真实姓名与登录手机号；手机号中间四位脱敏。 |
| 性别 | 基本认证资料 | 展示当前保存的性别。 |
| 年级 | 教师授课资料 | 展示已选择的授课年级。 |
| 学科 | 教师授课资料 | 展示已选择的授课学科。 |
| 教师类型 | 教师类型维护、编辑教师中的类型选择 | 有二级类型时展示“一级类型 / 二级类型”；未选择二级类型时仅展示一级类型。 |
| 主讲科目、教学经验 | 页面展示资料 | 展示已保存内容。 |
| 授课时长 | 已完成授课统计 | 只读展示，单位为小时。 |
| 收藏人数 | 基础收藏统计、页面展示资料中的虚拟收藏人数 | 展示基础收藏人数与虚拟收藏人数合计，运营不得直接修改基础统计。 |
| 关联课程数 | 教师与课程关联关系 | 汇总当前教师已关联课程数量。 |
| 展示状态、审核状态 | 教师上架状态、教师审核流程 | 分别展示是否上架与当前审核结果。 |
| 最近更新时间 | 教师资料、页面展示资料保存记录 | 展示最后一次保存资料的时间。 |

- 操作固定按“查看、编辑、下架、作废、全部评价、关联课程、排序”排列；下架老师显示“上架”用于恢复展示。
- 前端展示排序仍从行内“排序”进入，改为按默认范围和教师类型范围分别维护：未选择教师类型时使用默认排序；选择一级或二级教师类型时使用该类型的独立排序。当前老师只维护其已关联类型的排序值，不在教师列表保留独立摘要列；排序值越大越靠前。

## 关键结论

- 课程卡已明确课程，直接进入既有确认订单页，不再通过详情底部选择课程。
- 教学经验案例保留并升级为提分案例，不新建重复内容模块。
- 底部咨询入口属于教师详情页内部业务弹窗，左侧导航需体现其归属。
- V2 详情页按参考图的内容顺序和视觉层级使用真实组件复刻，返回、三项锚点、课程下单、电话和在线咨询均绑定实际页面交互。

## 待确认问题

- 顾问联系电话和在线会话标识由独立咨询顾问维护页统一维护；教师通过单选关联一个顾问。真实 IM 服务地址与历史消息由后续数据交互阶段提供。
- Icon 图片上传的格式、大小、默认兜底策略沿用统一上传组件规范。

## 风险与依赖

- 教师评价汇总、授课时长、收藏人数需由服务端统计提供；前端展示配置不能替代服务端统计。
- 真实电话和 IM 能力受小程序或客户端平台能力限制。
