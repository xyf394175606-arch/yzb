# 需求变更：教师经验案例 Icon 配置

## 背景

教师详情页的教学经验案例当前只有序号、标题和描述，家长难以快速区分不同案例主题；编辑教师弹窗也缺少每条案例对应的前台 Icon 配置入口。

## 目标

为每条教学经验案例增加独立 Icon 上传配置，并在家长端教师详情页的对应案例中展示该 Icon，提升案例识别度。

## 输入来源

- 教师资料弹窗 / 页面展示资料 / 教学经验案例区域的原型评审反馈。

## 本次变更

### 字段与页面

- 编辑教师 / 页面展示资料 / 教学经验案例：表格新增 `案例 Icon` 列。
- 每条案例独立上传一个 Icon，不与教师头像、教师形象照片或其他案例共用。
- 教师详情页 / 教师简介 / 教学经验：每条已展示案例在标题左侧展示对应 Icon。

### 字段约定

| 字段 | 含义 | 展示规则 |
| --- | --- | --- |
| `teachingCaseIcon` | 教学经验案例 Icon 图片 | 归属单条案例，用于教师详情页该案例的图标展示 |
| `teachingCaseTitle` | 教学经验案例标题 | 与 Icon、描述、排序、是否展示共同维护 |
| `teachingCaseDescription` | 教学经验案例描述 | 展示在标题下方 |
| `teachingCaseSort` | 教学经验案例排序 | 数值越小越靠前，沿用现有案例排序口径 |
| `teachingCaseDisplayEnabled` | 是否展示 | 关闭后该案例及其 Icon 不在教师详情页展示 |

### 业务规则

- 每新增一条教学经验案例，均提供独立的 Icon 上传入口。
- Icon 只服务于该案例在教师详情页的展示，不进入老师列表、首页、活动页或购买流程。
- 案例关闭展示或删除时，对应 Icon 一并不在前台展示。
- 当前原型使用“已上传”样例表示 Icon 已配置；真实图片上传、存储与默认兜底图由开发阶段承接。

## 关键结论

- 变更范围为教师资料弹窗和教师详情页，不新增页面、弹窗或导航节点。
- 本轮保留原有标题、描述、排序、是否展示、删除操作，不改变案例录入主流程。

## 待确认问题

- 暂无。Icon 的实际尺寸、格式、大小限制可在开发实现时按统一上传组件规范补充。

## 风险与依赖

- 若后续允许案例 Icon 为空，需要由产品与开发补充详情页默认 Icon 策略。
- 图片上传服务需返回可用于详情页渲染的稳定访问地址。

## 下一步动作

- 开发实现案例级 Icon 上传和详情页展示时，按本文件字段与展示规则处理。
- 原型评审继续核对每条教学经验案例均可独立维护 Icon。
