# 需求分析

## 1. 背景与范围

本轮基于用户提供的优坐标家长端首页截图，改版家长端首页，并增加后台首页装修工作台。交付范围为移动端首页、PC 后台配置页及两者的 mock 联动，不接真实接口。

## 2. 业务规则

### 2.1 已确认需求

- 首页由 Banner、快捷入口、试听课、教师类型/教师推荐、精品课程、公众号关注和底部导航组成。
- 管理员可以编辑首页模块、调整排序、启停模块、保存草稿并发布。
- 草稿只影响后台预览，家长端只读取已发布版本。
- 新增、编辑、配置弹窗底部只保留“取消”和“保存”；删除位于列表行内。
- 教师类型首页入口继续遵循现有规则：一级类型配置，启用且允许前台展示、配置完整时才进入首页。

### 2.2 推测需求

- Banner 可能需要多条内容并按排序轮播。
- 课程与教师卡片可能需要从已有课程/教师资料中选择，而不是重复录入。
- 首页发布后需要刷新缓存或重新读取已发布版本。

### 2.3 暂不纳入范围

- 真实素材上传、裁切、尺寸校验和存储。
- 真实 API、数据库、权限中心和发布审核。
- 分城市、分用户群和多版本灰度发布。
- 教师/课程自动推荐算法和历史版本回滚。

## 3. 字段说明

| 模块 | 字段 | 展示/编辑规则 |
| --- | --- | --- |
| Banner | 图片、主标题、副标题、按钮文案、跳转目标、展示时间、状态、排序 | 图片和文案可编辑，原型使用示例素材 |
| 快捷入口 | Icon、名称、副标题、跳转目标、状态、排序 | 支持预览和启停 |
| 试听课 | 课程、封面、标题、标签、价格、状态、排序 | 选择样例课程，展示前台结果 |
| 教师类型 | 一级类型、Icon、主标题、副标题、首页展示、Icon 排序 | 复用现有教师类型入口规则 |
| 教师推荐 | 教师头像、姓名、类型、经验、评分、服务人数、排序 | 原型手动选择样例教师 |
| 精品课程 | 课程封面、标题、标签、价格、购买按钮文案、状态、排序 | 下架/读取异常显示异常态 |
| 公众号关注 | 图标/二维码、标题、副标题、按钮文案、状态 | 原型展示示例二维码占位 |
| 底部导航 | 图标、名称、目标页、选中态、排序 | 首页固定为默认选中；不允许全部关闭 |

## 4. 功能按钮与操作说明

| 按钮 | 触发 | 结果 |
| --- | --- | --- |
| Banner 轮播入口 | 点击左侧 Banner 轮播、Banner 模块行或编辑图标 | 打开 Banner 配置弹窗，并切换右侧 Banner 专属需求说明 |
| 编辑 | 点击其他模块的编辑图标 | 打开所属编辑弹窗 |
| 保存 | 填写合法配置 | 保存草稿、关闭弹窗、列表标记草稿 |
| 取消 | 编辑中退出 | 关闭弹窗，不改变草稿 |
| 启用/停用 | 列表行操作 | 更新草稿状态并刷新预览 |
| 删除 | 列表行操作 | 删除草稿中的模块项，保留确认提示 |
| 预览草稿 | 后台操作 | 手机预览读取草稿 |
| 发布 | 管理员操作 | 发布草稿；成功后前台读取新版本，失败保留草稿并提示重试 |
| 刷新首页 | 家长端操作 | 重新读取已发布版本并更新页面 |

## 5. PC/移动端差异

- PC：左侧模块导航、顶部系统栏、配置列表/编辑区、发布状态和手机预览。
- 移动端：390px 手机框，严格限制内容在手机区域内，展示真实首页模块与底部导航。
- PC 右侧黄色说明区仅面向评审者，移动端不显示内部规则和待确认项。

## 6. 页面内容说明

### 首页装修工作台

默认展示首页概览、模块状态、草稿/已发布版本、变更摘要和手机预览。模块导航可切换 7 个配置模块。

### 家长端首页

默认展示截图中的新版首页：定位、Banner、快捷入口、试听课、教师推荐、精品课程、公众号关注和底部导航。

## 7. 页面与跳转逻辑

后台首页装修工作台进入模块编辑弹窗；点击 Banner 轮播导航、Banner 模块行或编辑图标时打开 Banner 配置弹窗，并在右侧展示 Banner 专属需求说明；保存后回到工作台。预览草稿切换手机预览状态；发布成功后点击“查看家长端”进入首页并读取已发布配置。家长端点击 Banner、入口、课程、教师卡片、底部导航时显示对应目标页占位或结果提示。

## 8. 待确认问题

- Banner 轮播间隔和多条配置的真实规则。
- 首页是否需要城市、角色或用户群差异化。
- 课程和教师推荐是手动选择还是自动排序。
- 发布审核、预览链接、历史版本和回滚规则。
- 图片尺寸、裁切、存储和兜底图规则。

## 9. 原型设计输入

- PC 页面：优坐标后台 / 首页装修工作台；模块导航下挂 7 个配置子页/编辑弹窗节点，Banner 轮播节点直接打开 Banner 配置弹窗。
- 移动页面：优坐标家长端首页。
- 关键交互：编辑、保存草稿、取消、启停、删除、预览草稿、发布、发布失败重试、查看家长端、刷新首页。
- 关键状态：配置不完整、空状态、读取失败、发布失败、草稿与已发布差异、无权限提示。
- 黄色说明区：放字段来源、教师类型入口规则、发布规则、权限与待确认问题。

## 10. 通用交付信息

- 输入来源：用户提供首页截图、现有优坐标家长端首页原型、教师类型首页入口配置说明、项目 AGENTS.md。
- 关键结论：首页改版必须与后台配置联动评审。
- 风险与依赖：真实数据契约和素材规范未完成。
- 下一步动作：实现可交互 HTML，并用浏览器完成 PC/移动端验收。
