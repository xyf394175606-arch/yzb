# 需求分析

## 1. 背景与范围

本轮基于用户提供的优坐标家长端首页截图，改版家长端首页，并增加后台首页装修工作台。交付范围为移动端首页、PC 后台配置页及两者的 mock 联动，不接真实接口。

## 2. 业务规则

### 2.1 已确认需求

- 首页由 Banner、快捷入口、试听课、平台服务保障、教师类型/教师推荐、精品课程、公众号关注和底部导航组成。
- 管理员可以编辑首页模块、调整排序、启停模块、保存草稿并发布。
- 首页装修工作台模块列表仅展示模块主标题、启用状态、配置数量和更新时间，不展示模块副标题或摘要；模块配置详情仍在对应弹窗内展示。
- 草稿只影响后台预览，家长端只读取已发布版本。
- 新增、编辑、配置弹窗底部只保留“取消”和“保存”；删除位于列表行内。
- 教师类型与推荐配置展示全部可维护教师类型；后台勾选是首页展示的唯一控制条件，勾选即展示，未勾选不展示，不再受原有首页启用或允许展示状态限制。
- Banner 由多条轮播广告组成；每条广告独立维护图片、跳转目标、跳转地址和轮播时长，列表顺序即前台轮播顺序。
- Banner 支持在配置弹窗内新增和删除轮播项，至少保留一条；删除放在轮播项行内。
- Banner 配置弹窗展示图片上传入口和 400*300 图片尺寸提示，当前为原型上传占位，不接真实素材存储。
- 快捷入口采用与 Banner 一致的列表配置方式；每条维护入口名称、跳转目标和地址，支持新增、编辑和行内删除。
- 快捷入口数量最少 4 个、最多 10 个；达到边界时禁用对应新增或删除操作。
- 试听课改为固定三位广告位；维护一个用于前台区块展示的主标题，每个位维护配套图片、跳转目标和跳转地址；前台区块名称统一为“试听课”，不再展示价格作为模块名称。
- 试听课广告位固定为 3 个，不支持新增或删除；主标题或任一广告位字段不完整时，阻止保存或发布。
- 教师类型与推荐改为主标题加教师类型多选；精品课程同步改为主标题加课程分类多选。
- 精品课程通过课程分类读取平台课程库中的排序结果，不再在首页装修弹窗内新增、删除或逐条关联课程广告位。
- 新版家长端试听课区块展示预约课程卡片和试听课程卡片；教师推荐和精品课程支持按教师类型或学科展示标签切换。平台服务保障展示一张完整保障图片，并纳入后台配置。

### 2.2 推测需求

- 课程与教师卡片可能需要从已有课程/教师资料中选择，而不是重复录入。
- 首页发布后需要刷新缓存或重新读取已发布版本。

### 2.3 暂不纳入范围

- 真实素材上传、裁切、尺寸校验和存储。
- 真实 API、数据库、权限中心和发布审核。
- 分城市、分用户群和多版本灰度发布。
- 教师/课程自动推荐算法和历史版本回滚。

## 3. 字段说明

| 模块 | 字段 | 展示/编辑规则 |
| --- | --- | --- |
| Banner | 图片、跳转目标、跳转地址、轮播时长、列表顺序、删除、新增 | 每条轮播独立配置；图片仅支持 jpg/png 原型校验且不超过 2MB，尺寸提示暂按 400*300；标题、副标题、落播时间、圆角图片、知识点颜色、按钮文案、展示时间和指示点样式不在本页维护 |
| 快捷入口 | Icon、入口名称、跳转目标、地址、列表顺序、删除、新增 | 每条入口独立配置；Icon 支持 jpg/png 图片替换，原型限制不超过 2MB；至少 4 条、最多 10 条，名称、跳转目标和地址为必填 |
| 试听课 | 主标题、广告位 1-3 图片、跳转目标、跳转地址 | 固定三位广告位；主标题用于前台区块标题，并同步作为后台模块名称展示；每个位的跳转目标和地址控制前台点击去向，图片用于展示广告内容 |
| 教师类型与推荐 | 主标题、每类默认展示老师数、教师类型多选标签 | 主标题最多 10 字，用于前台“推荐老师”区块标题；展示全部可维护类型，勾选即首页展示、未勾选不展示；支持全选/清空和已选数量反馈；每类展示数为 1 到 20 的整数，按排序取前 N 位老师 |
| 精品课程 | 主标题、每类默认展示课程数、课程分类多选标签 | 主标题最多 10 字；每类展示数为 1 到 20 的整数，按课程排序取前 N 门；至少选择一个课程分类；前台展示已选标签，标签或课程卡片超出一屏时支持横滑 |
| 平台服务保障 | 模块主标题、1 张图片、跳转链接 | 固定 1 张图片和 1 个跳转链接，不支持新增、删除或排序；主标题最多 20 字，保存及发布时校验完整性 |
| 公众号关注 | 主标题、副标题、按钮文案、跳转链接、是否展示 | 交互参考快捷入口弹窗；开启展示时 4 个内容字段必填，关闭展示时前台隐藏卡片 |
| 底部导航 | 固定 5 项、展示标题、跳转页面、是否展示、选中态 | 固定为首页、全部课程、全部老师、消息、我的；后台可编辑标题、跳转页面和展示状态，不支持新增/删除/排序；首页必须展示，至少保留一个入口展示 |

## 4. 功能按钮与操作说明

| 按钮 | 触发 | 结果 |
| --- | --- | --- |
| 模块配置入口 | 点击左侧模块导航、模块行或编辑图标 | 打开所属配置弹窗，并切换对应模块的右侧需求说明 |
| 保存 | 填写合法配置 | 保存草稿、关闭弹窗、列表标记草稿 |
| Banner 上传图片 | 点击轮播项图片区域并选择 jpg/png | 合法文件更新当前草稿图片名；类型错误或超过 2MB 时提示失败 |
| 新增轮播 | 点击 Banner 弹窗底部“新增轮播” | 增加一条轮播配置草稿 |
| 删除轮播 | 点击轮播项行内“删除” | 从草稿移除该轮播；至少保留一条 |
| 快捷入口新增 | 点击快捷入口弹窗“新增入口” | 增加一条快捷入口草稿；达到 10 条后不可新增 |
| 快捷入口删除 | 点击快捷入口行内“删除” | 从草稿移除该入口；保留 4 条时不可继续删除 |
| 快捷入口 Icon 上传 | 点击入口 Icon 占位并选择 jpg/png | 合法文件更新当前草稿 Icon；类型错误或超过 2MB 时提示失败 |
| 试听课图片上传 | 点击广告位图片区域并选择 jpg/png | 合法文件更新当前草稿图片名；类型错误或超过 2MB 时提示失败 |
| 试听课保存 | 填写主标题及三个广告位必填字段 | 校验通过后保存草稿并关闭弹窗；不支持新增或删除广告位 |
| 教师类型保存 | 填写主标题、每类展示老师数并选择类型 | 校验主标题、1 至 20 的整数和至少一个类型后保存草稿；全选/清空仅作用于弹窗临时状态，保存后前台按排序展示每类前 N 位老师 |
| 精品课程保存 | 填写主标题、每类展示课程数并选择分类 | 校验主标题、1 至 20 的整数和至少一个分类后保存草稿；前台按排序展示每类前 N 门课程 |

| 公众号关注保存 | 编辑主标题、副标题、按钮文案、跳转链接和是否展示 | 开启展示时校验 4 个字段，成功后保存草稿并关闭弹窗 |

| 取消 | 编辑中退出 | 关闭弹窗，不改变草稿 |
| 启用/停用 | 列表行操作 | 更新草稿状态并刷新预览 |
| 删除 | 列表行操作 | 删除草稿中的模块项，保留确认提示 |
| 预览草稿 | 后台操作 | 手机预览读取草稿 |
| 发布 | 管理员操作 | 发布草稿；成功后前台读取新版本，失败保留草稿并提示重试 |
| 刷新首页 | 家长端操作 | 重新读取已发布版本并更新页面 |

## 5. PC/移动端差异

- PC：左侧模块导航、顶部系统栏、配置列表/编辑区、发布状态和手机预览。
- 移动端：390px 手机框，严格限制内容在手机区域内，展示真实首页模块与底部导航。
- PC 右侧黄色说明区仅面向评审者，移动端不显示内部规则和待确认项。

## 6. 页面内容说明

### 首页装修工作台

默认展示首页概览、模块状态、草稿/已发布版本、变更摘要和手机预览。模块导航可切换 7 个配置模块。

### 家长端首页

默认展示新版首页：定位、Banner、快捷入口、试听课、平台服务保障、教师推荐、精品课程、公众号关注和底部导航。试听课展示预约课程卡片与试听课程卡片；教师推荐和精品课程展示标签切换。

### 试听课配置弹窗

配置主标题和三个固定广告位。每个位包含图片上传入口、跳转目标和跳转地址；保存后前台草稿预览按三个位置刷新。主标题默认使用“试听课”，前台按新版首页结构展示预约课程和试听课程卡片。

### 教师类型与推荐、精品课程配置弹窗

教师模块维护主标题、每类默认展示老师数和教师类型多选标签：主标题最多 10 字，展示全部可维护类型；勾选即在首页展示，未勾选不展示；支持全选、清空与已选数量反馈，展示数为 1 到 20 的整数，至少选择一个类型。保存后前台按排序显示每类前 N 位老师，已选类型展示为标签，标签或老师卡片超出一屏可横滑。精品课程维护主标题、每类默认展示课程数和课程分类多选标签：字段规则与教师模块一致，前台按课程排序显示每类前 N 门课程。

### 课程选择页

课程选择页保留为课程管理参考页，不再作为精品课程首页配置弹窗的下级页面。精品课程按已选分类从课程库读取排序结果；课程库为空、读取失败和无权限时分别展示对应异常说明。

### 平台服务保障

后台配置弹窗维护模块主标题、1 张平台服务保障图片和 1 个跳转链接；主标题最多 20 字，不支持新增、删除或排序。家长端按已发布版本展示完整保障图片，点击图片显示目标页占位反馈。

### 公众号关注配置弹窗

采用快捷入口的字段化配置方式，维护主标题、副标题、按钮文案、跳转链接和是否展示。保存后草稿预览同步显示或隐藏公众号关注卡片。

## 7. 页面与跳转逻辑

后台首页装修工作台进入模块编辑弹窗；点击模块入口、模块行或编辑图标时打开所属配置弹窗，并在右侧展示对应专属需求说明；保存后回到工作台。精品课程配置通过分类多选和展示数量控制课程库排序结果；预览草稿切换手机预览状态；发布成功后点击“查看家长端”进入首页并读取已发布配置。家长端点击 Banner、入口、试听课广告位、课程、教师卡片、底部导航时显示对应目标页占位或结果提示，底部导航按已发布版本的标题、跳转页面和展示状态展示。

## 8. Banner 规则

- 配置对象：Banner 是首页轮播广告列表，不是单条首页文案配置。
- 必填条件：启用 Banner 发布时，至少存在一条轮播；每条轮播需要有图片、跳转目标、跳转地址和正整数轮播时长。
- 图片规则：选择 jpg/png；原型限制不超过 2MB；界面展示 400*300 尺寸提示，实际尺寸、裁切比例和存储方式待开发确认。
- 跳转规则：跳转目标表示业务目标类型，跳转地址表示目标详情地址；两者需同时配置，地址格式和是否允许站外链接待确认。
- 时长规则：按秒填写正整数；具体最小值、最大值和异常提示文案待确认。
- 顺序规则：当前按配置列表顺序轮播；本轮不提供拖拽排序和优先级字段。
- 草稿规则：点击“保存，发布”只保存当前 Banner 配置到草稿并关闭弹窗；需在工作台点击“发布首页”后，家长端才读取新版本。
- 删除规则：删除只作用于草稿，至少保留一条轮播；删除入口位于轮播项行内。
- 未纳入字段：标题、副标题、落播时间、圆角图片、知识点颜色、按钮文案、展示时间、指示点样式和指示点颜色均不进入本轮 Banner 配置。

## 9. 待确认问题

- Banner 图片实际规格、裁切和存储规则。
- 跳转目标枚举、跳转地址格式及站外链接限制。
- 轮播时长最小值、最大值、默认值和异常提示。
- 是否需要拖拽排序、优先级和发布前预览真实轮播效果。
- 快捷入口 Icon 是否支持上传、跳转目标枚举、地址格式和排序方式。
- 首页是否需要城市、角色或用户群差异化。
- 课程分类、真实排序字段、可售状态口径、价格/销量刷新口径和课程分类的权限校验。
- 分类下课程不足展示数量、课程下架或读取失败时的前台兜底展示。
- 教师推荐的真实排序口径和数据来源。
- 发布审核、预览链接、历史版本和回滚规则。
- 图片尺寸、裁切、存储和兜底图规则。
- 试听课广告图片的实际尺寸、格式、大小、裁切和兜底图规则。
- 试听课跳转目标枚举、跳转地址格式，以及三个固定广告位未来是否允许动态化。
- 教师类型与老师列表的真实数据来源、类型可用状态、排序口径、无老师时的兜底展示和权限校验。
- 平台服务保障图片尺寸、格式、大小、裁切、兜底图、跳转地址格式和真实服务页面枚举。

## 10. 原型设计输入

- PC 页面：优坐标后台 / 首页装修工作台；模块导航下挂 8 个配置子页/编辑弹窗节点，每个模块入口直接打开所属配置弹窗，包含平台服务保障配置页。
- 移动页面：优坐标家长端首页。
- 关键交互：编辑、保存草稿、取消、Banner 图片上传、新增轮播、删除轮播、快捷入口新增、编辑、行内删除、4/10 数量边界校验、试听课主标题编辑、教师类型多选与标签切换、精品课程分类多选与标签切换、每类课程展示数量校验、固定三位完整性校验、试听课预约/课程卡片点击、教师/课程标签切换与横滑、平台服务保障图片点击、启停、预览草稿、发布、发布失败重试、查看家长端、刷新首页。
- 课程选择页：作为课程管理参考页面；支持课程库筛选和可售课程查看，不再作为精品课程配置的下级页面。
- 关键状态：配置不完整、空状态、读取失败、发布失败、草稿与已发布差异、无权限提示。
- 黄色说明区：放字段来源、教师类型入口规则、发布规则、权限与待确认问题。

## 11. 通用交付信息

- 输入来源：用户提供首页截图、现有优坐标家长端首页原型、教师类型首页入口配置说明、项目 AGENTS.md。
